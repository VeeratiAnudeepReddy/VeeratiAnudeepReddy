<h2 align="center">Featured Projects</h2>

### [AI Railway Optimization Platform](https://github.com/Digital-India-Hackathon-2026/hawkins-crew)

Accessibility-first route finder across an 8,737-station database covering 64% of the railway network, using time-expanded graphs and CP-SAT constraint optimization.

`Stack:` Python, CP-SAT, Graph Algorithms

---

### [Civix — Civic Issue Reporting Platform](https://github.com/VeeratiAnudeepReddy/Micro-Task)

Full-stack civic issue reporting platform with GPS tagging, AI-powered validation, and real-time tracking; reached 50+ users in testing. 🏆 1st Place, Webathon 4.0 (1000+ participants).

`Stack:` React.js, Node.js, MongoDB

---

### [AI-Based Urban Traffic Flow Optimization System](https://github.com/VeeratiAnudeepReddy/DES_OI_Hawkins-Crew)

Adaptive traffic signal control using YOLOv8 + OpenCV for real-time vehicle detection, cutting total waiting time by 29.89% vs. fixed-timing signals (SUMO-validated). 🥈 First Runner-Up, VNR Designathon 2026 (Open Innovation Track, top 30 of 2800+ registrations).

`Stack:` YOLOv8, OpenCV, SUMO, Python
